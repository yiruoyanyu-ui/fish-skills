# 硬字幕（Subtitles Burn）· v0.1

对标：Higgsfield subtitles（四步：转录→核对→烧录→复核，失败退回无字幕版）——其失败降级与"转录是烧录的地基"思想已吸收；其沙箱脚本绑其平台，烧录用本地 ffmpeg/PIL。

## 流程（骨架的字幕实例化）

1. **缺行检查**：视频源（或 底图+音频 自合成）＋ 字幕来源必有。字幕来源优先级：**用户提供 SRT/时间轴 > ASR 转写（均分时间轴，声明近似）> 用户文稿均分**。ASR 转写须清洗伪影（本平台已知伪影：`<|speaker:N|>`、`[回声]` 类环境标签）。
2. **ASR（转写模式）**：`speech_to_text`；**档位纪律**：字幕场景用 flash（≈8.3cr/秒）——字幕容忍小错别字，pro（50cr/秒）只在"转写即交付文本"场景用。
3. **分段**：按标点切句；均分时长时按字数加权（长句多给时间），首尾对齐音频实际时长。
4. **渲染烧录**：ffmpeg（帧合成/concat 或 overlay）；样式默认白字黑边底部居中，字号=画高×5.4%；**烧录前逐帧抽查**（AI 有视觉时自检，无视觉时抽帧给用户）。
5. **QC 与交付**：元数据级（时长对齐音轨、尺寸、码率）+ 像素级（字幕不越界、不压主体、断句合理）+ **精度声明**（均分时间轴=近似同步，逐字精同步待平台时间戳）。失败退回无字幕版+字幕文件（SRT），不冒充成品。

## 平台缺口登记（本页依赖）

- ASR 无字级时间戳；TTS-with-timestamps 未通过 MCP 暴露（内部 API 已有）→ 字级精确同步是本页 v0.2 的前置条件
