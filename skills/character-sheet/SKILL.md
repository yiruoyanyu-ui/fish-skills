# Character Sheet · v0.1-candidate.3

Experimental. This revision has not completed artifact acceptance.

## Define what the sheet must communicate

Reuse the user's character brief, images, requested panels and output format. A sheet shows one design across views or expressions; distinguish this from a cast of different characters. A prompt-only request returns the prompt. A generation request produces the requested image(s), not only a specification.

Separate supplied identity facts from proposed design choices. With a source character, preserve its visible face/shape, hair, clothing and accessories unless a change is requested. An unseen back or unclear detail is unknown; for concept design a coherent proposal may fill the gap, but exact reproduction requires an adequate reference. Describe proposals as choices, not observations.

Select the views needed for the intended use: front/side/back for a turnaround, face and full body for appearance, or named expressions for acting. Use the requested count. Name view directions consistently: a side profile and a three-quarter view are different views; do not give the same panel contradictory angles. If layout is unspecified, choose a simple readable arrangement and suitable canvas. Background, labels, pose, style, skin treatment and props follow this task. There is no universal white-background, standing, matte-skin or no-text requirement.

## Build a consistent visual reference

Describe the character once, then assign each panel its view or expression. Explicitly carry the same identity and unchanged costume through the panels. When an asymmetric detail matters, distinguish the character's own left/right from the viewer's left/right, and carry that meaning through changes of view. In a front view, the character's right is normally the viewer's left; turning the character does not move an accessory to the other side of its body. A back view need not invent a second facial design. Keep the sheet readable for its intended reference use.

Use a current image/reference-editing path compatible with the supplied material. When a chosen character already exists, reuse that result as the appearance reference; creating every later view from unrelated text alone risks identity drift. A grid can be generated as one image when supported. Separate images are appropriate when required or when a crowded sheet prevents useful detail; include them in the estimate.

Write only instructions needed to specify identity, panel roles, unchanged traits and the requested style. Do not add a realism module to a stylized brief. Keep user-requested objects, labels and clothing marks.

## Check and revise the requested difference

Check panel count, view direction, usable framing, identity, costume and meaningful accessories against the brief/reference. Distinguish visible agreement from uncertain fine detail. Generated consistency is not a guarantee of production-ready 3D topology, physically exact turnarounds or biometric identity.

For an edit, use the current sheet/reference and name what changes and what remains. Inspect every panel after the edit; do not assume a single successful panel proves consistency. Fix the specific defect within the authorized attempts, retaining all results. Deliver the sheet, intended reference use and unresolved mismatches.
