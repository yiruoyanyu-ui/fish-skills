## A. 抽象卖点可视化映射表

| 卖点/概念 | 画成 ✓ | 别画成 ✗ | 依据 |
|---|---|---|---|
| 降噪/静音 | 锯齿声波线涌来、在产品处变平直细线（动线横穿） | 粒子爆散、隔音罩壳、静电图罩 | [实证] 声波可读形态=线；粒子=爆炸语义 |
| 防水 | 水珠在表面成珠滚落、泼水弹开 | 产品泡在水里、水下场景 | [候选] 拒水=成珠 |
| 快充 | 电弧/光流**灌入**设备接口 | 闪电劈在产品上 | [候选] 闪电=雷击损坏隐喻 |
| 保温/保冷 | 杯身凝水珠或微霜、外界暖光被隔在背景 | 杯口蒸汽 | [实证] 蒸汽=保温失效暗示 |
| 轻盈 | 两指捏持/悬浮配软影 | 羽毛堆砌、天平 | [候选] 悬浮+影=失重叙事 |
| 续航 | 一条细光带缓慢环体流动 | 电池图标、倒计时沙漏 | [候选] 图标=图形风违规 |
| 天然/有机 | 真实原料入画（一滴源、一片叶） | 满屏绿色渐变 | [候选] 绿色滥用=俗套 |
| 强劲动力 | 少量速度线/被推开的空气 | 火焰爆炸背景 | [候选] 爆炸=失控 |
| 智能互联 | 设备间 1-2 条细光弧 | 全屏网状连线 | [候选] 网线=凌乱 |

## B. 材质词库

- **高级感词（写到"能摸到"）**：头层皮革纹理、拉丝金属、阳极氧化铝、微磨砂玻璃、织物声学面料、精密缝线、铰链五金
- **禁词（除非用户点名）**：plastic、shiny plastic、glossy CGI、3D render look
- 规则：主体至少一处纹理词；一词之差掉一档（实证：plastic→CGI 光滑感）

## C. 构图与色彩纪律

- 能量动线横穿画面，产品=动线上的转换器；禁半边能量半边空
- 全图一个高饱和主角色，背景低饱和；禁双高饱和对撞
- 悬浮产品默认配 glossy surface + soft reflection
- 每张自检：缩到 120px 宽还能认出"这是什么、什么情绪"

## D. AI 俗套黑名单

橙蓝撞色 / 紫青渐变 / 火花粒子 / 发光轮廓滥用 / "dramatic lighting"类抽象词 / 8K masterpiece 词堆 / 字面冰火两重天 / 满屏光斑虚化

## E. 视角与诚实

- 人眼尺度默认（相机能拍到的画面）；太空/剖面/内部结构=教学视角，用户点名才用
- 放大上限：只放大一件真实故事元素；外行看图反应应是"为什么"而非"不可能"
- 产品完整不拆解，不编造不存在的功能效果（诚实律）
