# Candidate Taste-Rule Generator

Input: product <name>; actual selling points <one to three>; deliverable <thumbnail, product photo or video frame>.

Generate five to eight candidate visual rules. All outputs are **candidate / untested**, not proven defaults.

1. Explain the real physical process behind each supplied benefit and identify an informative instant. Do not invent capabilities.
2. Translate it into a scene a camera could capture at human eye level. Mark internal/microscopic/space views educational and exclude them unless explicitly requested.
3. Choose readable energy language when needed: sound as lines/ripples, electricity entering the correct interface, light as a beam/attenuation, heat as a scene-appropriate boundary. Category-specific rules, such as a thermos steam restriction, are not universal physical laws.
4. Name actual tactile product materials. Avoid changing a plastic product into metal merely to make it appear premium.
5. Write a generic cliché version and a topic-specific alternative; select the alternative. Use one dominant saturated element with subordinate background.
6. Add an attention hook only when it supports the concept: one credible enlarged story element, justified foreground detail or a clearer grade. The concept outranks empty visual spectacle.
7. Check one-second recognition at 120 pixels, credibility and truthfulness to the actual product. Revise any candidate that fails.

Return a table of rule, proposed visual, avoided visual and reasoning. Mark every row candidate / untested. End with a one-sentence explanation for an unfamiliar viewer that creates a genuine question. This draft does not authorize media generation or promote a rule without evaluation.
