The captured HF method was: request workflow directory → get_workflow_instructions for an ID → get_workflow_bundle_file for required references → the user's Agent calls generation and assembly tools. A returned workflow is Skill-like guidance, not proof that one MCP call autonomously executes and bills the entire pipeline. Each Fish adaptation needs its own tool mapping and actual evidence.
